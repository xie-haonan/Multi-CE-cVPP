本页基于设备安装容量（kW）与净购电（kWh）等系统级输入，展示建设期原材料、合并能源路径、空气污染物及 CO₂-eq / SO₂-eq / PM2.5-eq 等效排放的聚合结果。图表数据为预计算 JSON 快照，便于公开展示与路演；可运行内核与因子库在受控私有仓库。

保密与边界：此处不包含业务敏感时序数据、实盘策略与完整因子溯源表。合作洽谈可在 NDA 框架下审阅私有核心仓库与论文级数据锚点。
