# ASSUMPTIONS

## 1. 时间尺度与建模范式

- 时间离散：默认采用小时级离散步长（1 h）
- 建模范式：稳态/准稳态逐时求解，不在本仓库展示瞬态 PDE/DAE 内核
- 数值稳定：公开接口要求显式说明步长敏感性与收敛判据

## 2. 物理守恒前提

- 质量守恒：任一控制体满足 `dm/dt = Σm_in - Σm_out + m_source`
- 能量守恒：任一控制体满足 `dE/dt = ΣQ - ΣW + Σ(m*h)_in - Σ(m*h)_out`
- 第二定律约束：总熵产 `S_gen >= 0`

## 3. 系统边界

- 能流域：电、热、冷、燃料与可回收副产物
- 市场域：电价、碳税/碳交易、绿证、污染物费用
- 生命周期域：设备、运行、替代效益与外部性核算

## 4. 公开与私有边界

- 公开：接口、方法说明、数学边界、展示图表
- 私有：可执行调度算法、生产级参数库、业务侧数据资产

## 5. 参数透明性原则

- 若参数来源于公开标准，应注明文献或标准号
- 若参数来自企业内部测试，不在本仓库给出具体数值
- 若存在关键参数不确定性，应给出敏感性分析建议区间而非单点“拍脑袋”值
